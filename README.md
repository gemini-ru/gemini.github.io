# StudyAI — Gemini + PDF-учебники

Готовый статический сайт для GitHub Pages.

## Файлы

Положи рядом с `index.html` такие PDF:

- `geometry.pdf`
- `algebra.pdf`
- `physics.pdf`
- `history.pdf`
- `chemistry.pdf`
- `geography.pdf`

Структура:

```text
/
├─ index.html
├─ app.js
├─ style.css
├─ geometry.pdf
├─ algebra.pdf
├─ physics.pdf
├─ history.pdf
├─ chemistry.pdf
└─ geography.pdf
```

## Запуск на GitHub Pages

1. Загрузи `index.html`, `app.js`, `style.css` в корень репозитория.
2. Загрузи 6 PDF с точными именами выше.
3. В GitHub открой **Settings → Pages**.
4. В **Build and deployment** выбери публикацию из ветки `main` и папки `/ (root)`.
5. Открой опубликованный адрес сайта.
6. Нажми `⚙` и введи Gemini API key.

## Важная безопасность ключа

GitHub Pages — статический хостинг. Если вставить API-ключ прямо в `app.js`, его смогут увидеть посетители сайта и исходный код. Поэтому этот вариант НЕ содержит ключ в репозитории: ключ вводится в интерфейсе и сохраняется только в `localStorage` текущего браузера.

Для публичного сайта с одним общим ключом лучше использовать серверный прокси (например, свой backend/Cloudflare Worker) и хранить ключ как секрет на сервере.

## Ограничение PDF

Текущая версия использует inline PDF и специально ставит локальный предел в 35 МБ на один учебник, чтобы не раздувать браузерный запрос. Gemini поддерживает PDF и рекомендует Files API для больших файлов и повторного обращения к документу.

## Как работает

Выбираешь предмет → вводишь `№ 17`, `§ 12` и т. п. → выбираешь действие:

- **Ответ на задание** — решает конкретное задание из PDF.
- **Конспект параграфа** — делает структурированный конспект.
- **Краткий пересказ** — пересказывает параграф простыми словами.
- **Объяснить тему** — объясняет тему и приводит пример.

Режимы:

- **Кратко** — минимум текста, удобно переписать.
- **Обычно** — больше объяснений и шагов.
